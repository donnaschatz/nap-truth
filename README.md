
# nap-truth

## Overview
This repository contains a classified, server-agnostic analysis of the NAP 20 Protocol—a recurring socio-economic structure observed in kingdom-builder war games. The main document (`index.html`) provides a deep dive into the function, incentives, and lifecycle of the Non-Aggression Pact (NAP) phenomenon, exposing how it stifles competition and leads to server stagnation and death.
